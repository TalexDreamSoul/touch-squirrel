# 松果仓品牌 IP

**松果仓**是 `touch-squirrel` 运行时的产品品牌。它把账号、凭证、密钥和号池视为需要被安全收纳、持续盘点并准确派发的“松果”。

> **囤得住 · 派得准**

![松果仓品牌 IP v2 设定板](v2/approved/brand-ip-board.png)

这张设定板用于视觉方向判断；下方文字规范是颜色、命名和使用边界的唯一准确来源。需要生产级 Logo 时，应基于批准方向重建受控 SVG，不直接描摹生成图像。

## 品牌结构

| 层级 | 名称 | 用途 |
|---|---|---|
| 产品品牌 | 松果仓 | 面板、README、公开文档与视觉传播 |
| Runtime | `touch-squirrel` | 架构、包和系统语境 |
| CLI | `squirrel` | 命令行与二进制名称 |
| 仓库 | `touch-xai-register` | 历史仓库名，逐步弱化但不影响兼容 |

公开界面优先写“松果仓”。只有讨论实现、兼容或命令时才使用英文 Runtime 和仓库名。

## 核心理念

- **仓**：所有产物有来源、状态和去向，不让凭证散落在脚本与临时目录中。
- **囤**：持续积累可用资源，但不追求无意义数量；健康和可追溯优先。
- **派**：按需求、状态和配额准确分发，失败能够回到任务与日志定位。
- **静**：高频控制面保持低噪声；品牌不抢操作信息的注意力。

## 视觉原则

1. **真实产品优先**：宣传图先展示控制台、流水线或产物，不用吉祥物代替产品。
2. **插画必须有职责**：松鼠只用于初次引导、空状态、成功反馈、流程解释和品牌页。
3. **橙色必须克制**：产品界面中的松鼠橙建议低于画面面积 7%；品牌板可放宽到 12%。
4. **一屏一个动作**：松鼠只做收货、盘点、搬运或派发中的一个动作，不堆叠剧情。
5. **保持成人工具感**：使用几何扁平或细线稿，不使用 3D 潮玩、毛绒质感和儿童贴纸风。

## 松鼠不变量

任何新插画都必须保留以下识别特征：

- 直立双耳；
- 橙色头部与大卷尾；
- 白色口鼻与腹部留白；
- 蓝色眼睛，但蓝色只属于角色身份，不进入产品主色；
- 紧凑、稳定的轮廓；
- 与松果、仓位、清单或派发动作至少建立一种关系。

禁止增加服装、工具腰带、机械义肢或无关道具。禁止在同一画面生成多个造型不一致的松鼠。

## 形态层级

| 形态 | 使用场景 | 规则 |
|---|---|---|
| 像素头像 | 16–48px、侧栏、favicon | 使用 `panel/public/brand/squirrel-icon.png`，不要再缩复杂全身像 |
| 扁平全彩 | 品牌页、宣传图、较大空状态 | 橙色主体，白色留白，石墨描边；背景保持中性 |
| 单色线稿 | 引导、说明图、产品内插画 | 石墨线条为主，只允许松果或一个局部使用橙色 |
| 构造符号 | 状态点、分隔或流程节点 | 只使用松果、卷尾曲线或仓位，不单独使用随机爪印 |

## 色彩

| 角色 | 色值 | 使用边界 |
|---|---|---|
| 画布白 | `#FCFBF9` | 品牌图背景；产品可使用纯白 |
| 石墨黑 | `#333333` | 标题、线稿和高对比正文 |
| 中性灰 | `#D2D2D1` | 分隔线、禁用态和次级结构 |
| 松鼠橙 | `#F98530` | 主操作、选中态和松鼠主体；不可做大面积页面背景 |
| 松果棕 | `#AD6630` | 松果与少量材质细节 |
| 眼睛蓝 | `#2D5294` | 只用于松鼠眼睛或原始头像身份细节，不作为 UI 强调色 |

成功、警告、错误继续使用产品语义色，它们不是品牌色。品牌传播中不要把蓝色重新提升为主色。

## 产品内使用

- 主要操作允许使用松鼠橙；同一视图只保留一个强橙色动作。
- 选中态可用 2px 橙色短线或小面积图标，不使用整块橙色导航背景。
- 卡片、面板和页面背景保持白色或中性灰，不做橙色渐变。
- 松鼠插画不超过所属区域高度的 35%，不遮挡表单、状态和按钮。
- 相同页面只出现一个完整松鼠；Logo 中的小头像不计入完整插画。

## 文案语气

品牌语气是**清楚、可靠、稍有温度**。句子先说状态，再说动作；不写夸张承诺或拟人化段子。

| 场景 | 推荐 | 避免 |
|---|---|---|
| 成功 | `已入库 12 份凭证` | `松鼠帮你囤好啦！` |
| 空状态 | `还没有可用凭证` | `仓库空空如也，快投喂松鼠吧` |
| 派发 | `已分配 3 个任务` | `松鼠正在疯狂派单` |
| 错误 | `探活失败，可查看运行日志` | `糟糕，松鼠迷路了` |

Slogan 只用于 README、品牌页和发布物，不放在高频操作界面中。

## 新资产检查

发布前逐项确认：

- 名称使用“松果仓”，不是 `touch-squirrel` 主标题；
- 画面主角是产品或具体动作，不是无意义吉祥物展示；
- 橙色面积符合使用场景上限；
- 松鼠身份特征一致，身体和尾巴没有漂移；
- 图内没有随机文字、水印、错误标签或敏感数据；
- 16–48px 使用像素头像，较大场景才使用全身或线稿；
- 技术架构、流程和数据关系优先使用 Mermaid/SVG，而不是生成式图片。
