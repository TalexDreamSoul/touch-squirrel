# 生成提示词存档

复现或迭代品牌资产时直接复用。工具：git-wiki MCP `prompt_asset_generate_image`。

> 生图 API 只支持 `1024x1024` / `1024x1536` / `1536x1024` 三种尺寸，无法直接产出小图标。
> `icons/` 下的全部尺寸均由 1024 源图经 Lanczos 降采样得到，见 `scripts` 段。

## logo-mark-head.png（派生，非生成）

不是生图产物，从 `logo-mark-flat.png` 程序化派生：

1. 在 y∈[110,340]（耳部行，此区间尾巴尚未与头部相连）用 IoU 搜索垂直对称轴 → **x=512，IoU 0.926**
2. 裁左半 `(512-272, 100) → (512, 712)`，水平镜像拼出右半

   镜像而非矩形裁切，是因为 y≥400 后尾巴与头部是同色连通区域，矩形切法必然在右边缘留下一条尾巴残片。
3. 按 alpha 实际内容重新定界 → 补成正方形 → 四周留 8% 安全边距

## 尺寸序列

三套 `icons/*` 均由对应 1024 源图用 PIL `Image.LANCZOS` 一次性降采样到 16/32/48/64/128/256/512/1024，PNG `optimize=True`。

## 关于「反推提示词」

尝试过 `prompt_asset_reverse_publish`，失败：返回 `image_fetch_failed`。

该工具只接受 `image_base64` 或**公网可抓取**的 `image_url`。wiki 上的生成图是 `visibility: private`，服务端抓取被登录态拦下（直接 curl 同样返回 `{"error":"login_required"}`）；而 base64 走工具参数需要逐字符传约 1MB 文本，不可行。

好在没有必要 —— 上面记录的是**实际生成时用的原始提示词**，比任何反推近似都更准确。
