## 任务不动

先看当前阶段、worker PID 和 run 日志。配置抓取失败、邮箱收码超时、打码失败和 OAuth 失败是四类不同问题，不能统一叫“注册失败”。

## 吞吐过低

浏览器打码为串行时，S 就是上限。先测 token mint 耗时、代理质量和邮箱延迟，再考虑切换 solver 或调整并发。

## 联邦没有分配

确认从节点 role、主地址、联邦 token 和 heartbeat；再确认主节点是否已经达到目标，或从节点是否报告 busy。没有 assignment 不一定代表连接失败，可能只是没有缺口。

## 阅读故事

排障像查一条停住的传送带：先看电源和当前卡点，再看上一站有没有供料，最后才考虑加速。把所有故障都叫“机器坏了”，修不好任何一处。
