## 每次任务都有独立产物

每个 run 分目录保存 SSO、会话、CPA 与 discarded。成功 CPA 是独立 JSON 文档；本地池用于节点内管理，CPA Management 可用于远端存储和分发。

## 巡检与补号

巡检要区分暂时限流、凭证失效和额度耗尽。补号是独立动作，不应和清理绑定在一起，否则一次误判会同时丢失凭证和补充能力。

## 配置分享的边界

配置链接只分享邮箱、TouchMail、代理和 clearance 等非敏感字段，并以非空合并导入。CPA 密钥、集群密钥、状态页密码和本机路径不在共享范围内。

## 阅读故事

凭证像仓库里的封条：每一批货都要有自己的箱号和入库单。共享的是收货流程，不是仓库钥匙和保险柜密码。
