## 前台命令不直接注册

启动 `xai-accounts` 后，前台命令先创建本次 run 的状态：目标数、日志路径和输出目录。随后它以同一可执行文件重新拉起独立的 `--worker` 子进程，真正执行注册。

## 为什么要分开

前台负责启动、停止和查看状态；worker 负责耗时工作。PID 文件和独占锁保证同一个根目录同一时间只有一个注册 worker。

停止时，worker 会先停止生产新任务，再让已经在 OAuth 队列里的工作收尾，避免账号刚注册成功就被无序切断。
